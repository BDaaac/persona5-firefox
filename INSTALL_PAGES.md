# Phantom Start в обычном Firefox

Адрес сайта: <https://bdaaac.github.io/persona5-firefox/>.
Сайт работает на GitHub Pages; запускать локальный сервер или устанавливать наше
неподписанное расширение не требуется. Для загрузки нужен интернет.

## При запуске Firefox

1. Откройте `about:preferences#home`.
2. В «Домашняя страница и новые окна» выберите «Мои URL…».
3. Вставьте `https://bdaaac.github.io/persona5-firefox/`.
4. Если хотите видеть стартовую страницу при каждом запуске, откройте
   `about:preferences#general` и отключите восстановление предыдущих окон и вкладок
   («Открывать предыдущие окна и вкладки»).

Страница также доступна кнопкой «Домой» или `Alt+Home`.

## В каждой новой вкладке

1. Установите [New Tab Override от Sören Hentzschel](https://addons.mozilla.org/firefox/addon/new-tab-override/).
2. Откройте настройки дополнения сочетанием `Shift+F12` или через `about:addons`.
3. Выберите вариант своего URL и вставьте `https://bdaaac.github.io/persona5-firefox/`.
4. Если хотите сразу управлять меню с клавиатуры, включите фокус на странице
   вместо адресной строки. Это необязательно.
5. Откройте `Ctrl+T`. Если Firefox спросит, подтвердите сохранение новой вкладки.

Для замены новой вкладки используйте только одно дополнение. Если наша временная
версия Phantom Start ещё загружена, удалите её в `about:debugging`.
Настройка New Tab Override сохраняется после перезапуска Firefox.

## Звук и данные

- Музыка включается в Config. Firefox может требовать первый клик для звука.
- Звук смены дня запускается автоматически при первом открытии в новый день и
  не зависит от переключателя фоновой музыки. После календаря открывается Search / Joker.
- Чтобы звук смены дня играл без клика, откройте сайт, нажмите `Ctrl+I` →
  «Разрешения» → «Автовоспроизведение», снимите «По умолчанию» и выберите
  «Разрешить аудио и видео». Firefox запомнит разрешение именно для этого сайта;
  менять общую защиту браузера не требуется. После изменения перезагрузите страницу.
  Если звук был заблокирован и календарь уже прошёл сегодня, в Config нажмите
  «REPLAY DATE INTRO», чтобы проверить звук.
- Ссылки и настройки сохраняются локально для этого сайта. Данные из `file://`,
  `localhost` и расширения автоматически не переносятся; ссылки нужно добавить заново.
- Новая вкладка — отдельная страница. Если включить музыку в нескольких открытых
  вкладках, они могут звучать одновременно; текущая версия приостанавливает музыку
  в скрытых вкладках.
- Полноценная работа без интернета не предусмотрена.

## Публикация обновлений

`main` содержит исходный код; `gh-pages` — только готовые файлы сайта.
`python scripts/build_pages.py` собирает сайт в `dist/pages-site/` по явному списку
`scripts/runtime_files.py`. Новую сборку необходимо опубликовать в `gh-pages`;
одного изменения `main` недостаточно. GitHub Pages настроен на корень `gh-pages`.
После публикации обновления достаточно обновить страницу (`Ctrl+F5` при старом кеше).
