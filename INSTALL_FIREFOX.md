# Phantom Start — установка в Firefox

Расширение содержит страницу, персонажей, фон, анимации и музыку. Сервер не нужен.
Новая вкладка и домашняя страница открывают Phantom Start. Интернет требуется только
для перехода на сайты, поиска, Google Lens и ChatGPT. Пакет не меняет оформление
панелей Firefox: для него по-прежнему используется `firefox-theme/userChrome.css`.

## Постоянная установка

Обычный Firefox устанавливает расширения только с подписью Mozilla.
Файл с `unsigned` в названии ещё не подписан и напрямую постоянно не установится.

1. Откройте <https://addons.mozilla.org/developers/addon/submit/distribution> и
   войдите в аккаунт Mozilla. Условия разработчика принимает владелец аккаунта.
2. Выберите распространение **On your own** / самостоятельно, без публичного каталога.
3. Загрузите `dist/phantom-start-1.0.0-amo-upload.zip`. В пакете нет сборки,
   обфускации или удалённого исполняемого кода; исходные HTML/CSS/JS включены.
4. Заполните сведения по фактическому содержимому. Это неофициальная фанатская
   страница Persona 5; происхождение игровых материалов указано в репозитории
   и `assets/audio/README.md`. Подпись зависит от проверки Mozilla.
5. После подписи скачайте выданный Mozilla файл `.xpi`.
6. В Firefox откройте `about:addons`, нажмите шестерёнку → **Установить дополнение
   из файла…**, выберите подписанный `.xpi` и подтвердите установку.
7. Подтвердите замену домашней страницы / новой вкладки, если Firefox спросит.
   Проверьте `Ctrl + T`. Если другое расширение управляет новой вкладкой,
   отключите для него эту функцию.

Документация Mozilla:
<https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/>

## Попробовать до подписи

Этот способ работает без сервера, но временное расширение удаляется после
полного закрытия Firefox. Для ежедневного использования нужна подписанная версия.

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение…**.
3. Выберите `dist/firefox-unpacked/manifest.json`.
4. Откройте новую вкладку (`Ctrl + T`).

## Сборка и проверка

В корне репозитория:

```powershell
python scripts/build_firefox.py
npx --yes web-ext@10.8.0 lint --source-dir dist/firefox-unpacked
```

Сборка создаёт архив для подписи, неподписанный XPI, распакованный пакет и
`dist/SHA256SUMS.txt`. В архив попадают только файлы из явного списка сборки;
локальные настройки агента, скриншоты, резервные копии и тестовые страницы исключены.

## Данные

Телеметрии и фоновых сетевых запросов нет. Ссылки, настройки музыки и отметка дня
сохраняются локально в хранилище расширения. Оно отдельно от хранилища прежней
страницы `file://` или `localhost`; ссылки при необходимости нужно добавить заново.
Поиск отправляет введённый текст выбранному сайту только после нажатия кнопки.
Фото загружаются пользователем непосредственно на Google Lens или ChatGPT.
У этих сервисов собственные условия обработки данных.
